## ✨ Key Highlights & Features

- **🏛️ Prestigious Legal Aesthetic**: Elegant deep burgundy and gold-accented palette with Google Fonts (*Cinzel* & *Poppins*).
- **⚡ Zero-Lag Performance**:
  - Hero background compressed by **>94%** (from 4.11 MB to 266 KB) with zero visible loss in quality.
  - Native `loading="lazy"` on below-the-fold media.
  - Hardware-accelerated CSS transforms for silky-smooth animations.
- **📱 Fully Responsive Layout**: Tailored viewports with adaptive grid systems and an intuitive mobile hamburger drawer.
- **📂 Practice Areas Showcase**: Dedicated cards covering Corporate, Banking & Finance, Environmental, Insurance, Real Estate, and Civil Litigation.
- **📰 Publications & Landmark News**: Real-time regulatory alerts, antitrust updates, and legal briefings.
- **📞 Consultation Workflows**: Direct click-to-call consultation actions and contact inquiries.

## 🚀 Running Locally

To run this project on your local machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/MOHAMEDASHIK54/Layers-Site.git
   ```
2. Navigate into the folder:
   ```bash
   cd Layers-Site
   ```
3. Open `index.html` in your favorite browser, or start a local server:
   ```bash
   npx serve .
   ```
